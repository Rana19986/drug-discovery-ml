🔬 What This Project Does

The pipeline accepts molecular structures represented as SMILES strings, converts them into machine-learning features, and uses an optimized XGBoost model to predict molecular solubility.

It also provides molecular analysis and explainability capabilities through a deployable REST API.

🧬 Scaffold Split Validation

R²: 0.8617

The model was evaluated using scaffold-based validation in addition to a conventional random split to better assess its ability to generalize across different molecular structures.

---

🧠 Why Scaffold Validation?

A random train/test split can place structurally similar molecules in both training and testing sets.

Scaffold splitting provides a more challenging evaluation by separating molecules based on their underlying chemical scaffolds.

This makes the 0.8617 scaffold-split R² an important indicator of model generalization.
